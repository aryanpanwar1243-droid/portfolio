# Aryan Panwar — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript and designed for GitHub Pages.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling and animations
- `script.js` — navigation and scroll reveal effects

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Push the files to a GitHub repository. Then open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.

## Before submission
Replace `your-email@example.com` in `index.html` with your actual email and update the GitHub/LinkedIn profile links.
